# DoctorWeb1 (DW-1)

Проект студентов НГУ (Институт интеллектуальной робототехники) по заказу компании **«Доктор Веб»**.  
**Тема:** Автоматизированная оценка AI-assisted происхождения электронных писем (EML, HTML, изображения) и локализация сгенерированных фрагментов.

---

## 🏗 Архитектура Системы (по ТЗ DW-1 v5)

Система построена по модульной конвейерной архитектуре (**L0 – L5**):

```
                       [ Вход: EML / HTML / Текст ]
                                    │
                                    ▼
       ┌────────────────────────────────────────────────────────┐
       │ L1: Разбор и зонирование (Subject, Greeting, Body, CTA)│
       └───────┬────────────────────┬───────────────────┬───────┘
               │                    │                   │
               ▼                    ▼                   ▼
       ┌───────────────┐    ┌───────────────┐   ┌───────────────┐
       │ L2: Текстовый │    │   L2: HTML    │   │  L2: Vision   │
       │  mDeBERTa-CRF │    │  Анти-сокрытие│   │  ИИ-картинки  │
       │  (по словам)  │    │  (CSS, ссылки)│   │  QR-код, OCR  │
       └───────┬───────┘    └───────┬───────┘   └───────┬───────┘
               │                    │                   │
               └────────────────────┼───────────────────┘
                                    │
                                    ▼
       ┌────────────────────────────────────────────────────────┐
       │ L3: Decision Engine (Композитный AI-индекс 0..1)       │
       │     Объяснение для аналитика SOC на русском языке      │
       │     Сериализация в единый JSON по стандарту ТЗ         │
       └────────────────────────────┬───────────────────────────┘
                                    │
                                    ▼
       ┌────────────────────────────────────────────────────────┐
       │ L4: Интерфейсы: CLI (`cli.py`), Web (`app.py`), Docker │
       └────────────────────────────────────────────────────────┘
```

### Основные компоненты:
1. **Текстовая модель (`src/model.py`):**  
   Архитектура `TNC-DBGC*` (`microsoft/mdeberta-v3-base` + Dynamic Dropout + BiGRU + CRF). Обеспечивает пословную классификацию и выявление точных символьных границ сгенерированных фрагментов в частично переписанных письмах.
2. **HTML-анализатор (`src/html_analyzer.py`):**  
   Детекция скрытых CSS-элементов (`display:none`, `font-size:0`, атрибут `hidden`), фишинговой подмены ссылок, Zero-Width символов (`\u200b`) и извлечение чистого видимого текста.
3. **Анализатор изображений (`src/image_analyzer.py`):**  
   Классификация сгенерированных картинок (`umm-maybe/AI-image-detector`), извлечение текста через `EasyOCR` и детекция QR-кодов (`OpenCV`).
4. **Конвейер принятия решений (`src/pipeline.py`):**  
   Расчет итогового индекса AI-генерации (0.0..1.0), вердикта (`AI-Generated` / `Human-Written`), формирование заключения для SOC и сборка JSON.
5. **Интерфейсы:**  
   CLI (`cli.py`), веб-сервис с тёмной темой (`app.py`), скрипты валидации (`evaluate.py`, `run_academic_validation.py`) и Dockerfile.

## 📁 Датасеты проекта и валидация

В рамках проекта используются и исследованы 3 группы датасетов:

### 1. Обучающий корпус `CoAT_Hybrid` (Sequence Labeling)
Разработан для обучения модели поиску точных границ перефразированных и сгенерированных фрагментов (стыков «Человек ↔ ИИ»).
* **Объём данных:** 17 136 гибридных текстов:
  * `train.csv`: **12 049** текстов (учебная выборка)
  * `val.csv`: **2 527** текстов (промежуточная валидация)
  * `test.csv`: **2 560** текстов (контрольный тест)
* **Структура склейки:** последовательности авторства `H_M` (Человек $\rightarrow$ Машина), `M_H`, `H_M_H`, `M_H_M`.
* **Разметка:** пословные метки `word_labels` (`0` — человек, `1` — ИИ) и координаты точек перехода `word_boundary_ix`.

#### Результаты валидации на тестовом сете CoAT_Hybrid:
| Метрика качества | Значение | Описание |
| :--- | :---: | :--- |
| **Accuracy по словам** | **90.6%** | Доля верно классифицированных слов |
| **Weighted F1** | **90.6%** | Сбалансированная точность и полнота |
| **Cohen's Kappa** | **0.8120** | Высокая согласованность с разметкой |
| **Boundary MAE** | **17.92** | Среднее отклонение координаты стыка (в токенах) |

### 3. Академическая валидация на датасетах преподавателя
Независимое тестирование компонентов решения на общепринятых бенчмарках (скрипт `run_academic_validation.py`):

| Бенчмарк | Модальность | Язык / Домен | Выборка | ROC-AUC | Accuracy | F1-Score | Recall | FPR | Статус |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **LLMTrace** | Текст | Русский (`ru`) | **200** | **0.349\*** | 45.5% | 0.620 | 89.0% | 98.0% | *Генерационный сдвиг* |
| **SeqXGPT** | Текст | Английский (`en`) | **200** | **0.454** | 48.0% | 0.464 | 45.0% | 49.0% | *Domain Shift (Язык)* |
| **Defactify** | Картинки | Фактчекинг / Мемы | **100** | **0.612** | 52.0% | 0.143 | 8.0% | **4.0%** | *Тип манипуляции* |
| **NTIRE (МГУ)** | Картинки | Диффузия (Midjourney)| — | — | — | — | — | — | *Gated (Требует токен)* |

#### Академические выводы:
1. **LLMTrace (Генерационный сдвиг):** Модель обучалась на `CoAT` (генераторы RuGPT-3 2021–2022 гг. со специфическими стилистическими артефактами). Современные LLM (GPT-4o, Claude 3.5, LLaMA-3) в `LLMTrace` генерируют идеальный академический русский язык, в то время как живые люди на форумах и в комментариях пишут с разговорным шумом. Это вызывает классический эффект *Concept Drift*.
2. **SeqXGPT (Языковой барьер):** Датасет `SeqXGPT` на 100% состоит из английского языка (`en-EN`). Точность 48.0% на англоязычном тексте экспериментально подтверждает специализацию модели DW-1 на русском языке (русский токенизатор `razdel`, веса BiGRU).
3. **Defactify (Специфика детекции картинок):** Классификатор `ViT` натренирован на артефакты диффузионных сетей (Midjourney/SD). На датасете `Defactify` (фотожабы, скриншоты, мемы) диффузионные шумы отсутствуют, что обеспечивает минимальный уровень ложных тревог (FPR = 4%), но низкий Recall на недиффузионных манипуляциях.
4. **NTIRE (МГУ):** Репозиторий является закрытым (Gated Repository) на Hugging Face и требует персонального токена участника соревнования.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
python -m venv .venv
source .venv/bin/activate  # На Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Поместите веса `tnc_dbgc_coat_best.pt` в корень репозитория.

---

### 2. Использование CLI (`cli.py`)

#### Анализ произвольного текста:
```bash
python cli.py analyze --text "Уважаемый клиент, ваш пароль скомпрометирован..." --subject "Безопасность"
```

#### Анализ HTML-письма:
```bash
python cli.py analyze --html email.html --output report.json
```

#### Анализ EML-письма (RFC 5322):
```bash
python cli.py analyze --eml samples/ai_phishing_evasion.eml --output report.json
```

#### Пакетная обработка каталога писем (до 1941+ писем):
```bash
python cli.py batch --dir data/emails_batch --output results/batch_summary.json
```

---

### 3. Запуск веб-интерфейса (`app.py`)

Для интерактивной демонстрации в браузере доступен локальный веб-сервис с тёмной темой:
```bash
python app.py
```
