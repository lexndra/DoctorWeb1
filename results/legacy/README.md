# Архив прежних результатов

`coat_test_metrics.json` — метрики первой модели TNC-DBGC* на корпусе CoAT_Hybrid (2023 г., генераторы прошлого поколения).
Сохранены для истории. По умолчанию `src/train.py` обучал на подвыборке (1200 train / 250 test, 2 эпохи), и какой именно
прогон дал эти цифры, восстановить нельзя, поэтому они **не** используются как метрики решения.

Прежние `evaluation_metrics.json` и `roc_curve.png` удалены: они считались на 20 написанных вручную письмах, где «ИИ-письма»
отличались вставленными признаками HTML-маскировки, а F1@3 был вписан в код константой.
Актуальные метрики: `results/metrics/report.md` (`python evaluate.py`).
